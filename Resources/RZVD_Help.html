Getting Started

  1. Paste a supported video URL into the Enter Video URL field.
  2. Select a download location.
  3. Choose a video or audio format.
  4. Click Start Download.
Download only media that you have permission or legal authorization to save.
Tested Working Platforms

  • YouTube Shorts
  • TikTok
  • Reddit

Available Formats

Video

  • MP4: Widely compatible with most devices and media players.
  • MKV: Flexible container with broad codec support.
  • WebM: Open format commonly used for web video.
  • WMV: Legacy format supported by Windows Media Player and most other media players.

Audio

  • MP3: Widely supported compressed audio.
  • WAV: Uncompressed audio with larger file sizes.
  • Ogg Vorbis: Open compressed audio format.
  • Opus: High quality audio format.

Tools

RZ's Video Downloader uses yt-dlp and FFmpeg. The application checks for and downloads the required tools automatically.

You can manually check them by opening the Tools menu and selecting Verify Dependencies.

Media Converter

RZ's Video Downloader is also bundled with a media conversion tool that can convert downloaded media to other formats. You can access it by opening the Tools menu and selecting Media Converter.

Available Video Conversion Formats

  • WebM

Available Audio Conversion Formats
  • MP3
  • WAV
  • Ogg Vorbis
  • Opus

Downloads History

You can view your download history by opening the Tools menu and selecting Open Download History.

The History Manager allows you to view and reopen or redownload previously downloaded media. You can also clear your history or export it to an Excel file for backup or record-keeping purposes.

Troubleshooting

The download will not start

Make sure the URL is valid, a download folder is selected, and the application has permission to write to that folder.

The dependency check failed

Check your internet connection and make sure security software is not blocking the application from downloading or running yt-dlp.exe and ffmpeg.exe.

The selected format is unavailable

Some websites or videos do not provide every format. Try selecting another output format and start the download again.
